# How other OneWheel events work — and what's different about TVS

---

## Typical US enduro weekend (DirtSurferz, Oak City, FLF)

| Element | Common pattern |
|---------|----------------|
| **Duration** | 3 days (Fri practice, Sat enduro, Sun XC/excursion) |
| **Format** | Multi-stage timed downhill segments; ride at your own pace between stages |
| **Practice** | Full day Friday, course open |
| **Categories** | Pro (ORL/FM regulated), Open (anything goes), Clydesdale (215+ lbs), Legends (50+), Men's/Women's |
| **Registration** | Event website or BikeReg; on-site waiver common |
| **Safety** | Helmet + wrist guards mandatory |
| **Timing** | RFID wrist/ankle bands (Zone4 at Oak City), or beacon systems (FLF/SI) |
| **Extras** | Head-to-head, endurance lap race, clinics, merch, camping |
| **Groms** | DirtSurferz 2026: guided groms race — adults lead and tail each group |

---

## UK / EU events (FTH, SIS, Shred the Shires, Surrey)

| Element | Common pattern |
|---------|----------------|
| **Duration** | 2–4 days |
| **Format** | Mix of enduro stages, sometimes head-to-head, trick comp, chair race |
| **Practice** | Often cut short; walkthroughs sometimes on foot |
| **Categories** | Pro/amateur splits have appeared (FTH) — controversial |
| **Registration** | WhatsApp chaos, on-site queues, occasional online waiver |
| **Timing** | Adam's custom system, Hermes phone GPS |
| **Pain points** | Fractured social scene, early starts, too much organiser talk, live stream quality |

---

## TVS differences (intentional)

| Area | Others | TVS |
|------|--------|-----|
| **Categories** | Pro/amateur/common | Open — no split; per-segment prizes |
| **Practice** | Often limited | Long windows Fri–Sat; trails stay open |
| **Walkthroughs** | In-person, sometimes hiking | Virtual video guides on website |
| **Briefing** | Mandatory 8am gathering | Prerecorded + online quiz; 10am start; optional attendance |
| **Registration** | On-site queues | Online waiver + briefing + QR before arrival |
| **Times** | Often live on phone | Hidden until prize giving |
| **Social** | Scattered | Central hub with chairs, bingo, fire |
| **App** | Some pushing custom apps | Website only |
| **Head-to-head** | Common at US events | Skipped — Glentress trails too narrow |
| **Trick comp** | Common | Skipped — no features, parent drama |
| **Timing tech** | Various | Exploring SportIdent (same as Glentress 7 MTB) |
| **Trail building** | Weeks of prep at some venues | Zero — use existing Glentress trails |
| **Profit motive** | Often break-even or loss leader | CIC, explicit break-even goal |
| **Volunteers** | Small insular group | Festival shift model, larger pool |

## What TVS explicitly drops

- Live drone stream
- Pro/amateur categories
- Mountain hike walkthroughs
- Mandatory early briefing
- DJ / expensive production
- Raffle (bingo instead)
- Andy-style overspending and control
- Separate download-an-app-for-each-event
- Trick comp / high jump
- Shitty STS prizes

## Competitive landscape timing

- Andy targeting FTH 2028 — TVS 2027 slots in before, different venue, different vibe
- Glentress already hosts 500+ person MTB events — infrastructure exists
- OneWheel Scotland / EOL community is the core audience; MTB tourists are bonus spectators

## Risk: being too different

| Risk | Mitigation |
|------|------------|
| Hidden times frustrate data nerds | Publish full results after prize giving; optional live "new fastest" without names |
| No categories means pros always win | Per-segment prizes; team race for groups |
| Online-only reg excludes technophobes | Paper waiver fallback at hub |
| Beacon timing unfamiliar | Clear briefing video; marshals at starts |
| Too hands-off on race day | Radio contact; marshals on gnarly trails; first aid on site |
