## Core principles (from the chat)

1. **Break even, not profit** — avoid "Andy vibes" spending; every financial decision gets the "is this Andy vibes?" test.
2. **Prep heavy, day-of light** — virtual briefing, online waiver, clear website; minimal mandatory gatherings.
3. **Riders first** — long practice, no mountain hikes in full gear, no closing trails during practice, sensible start times (10am).
4. **No pro/amateur split** — open format; per-segment prizes so everyone has a shot.
5. **One timed run per segment** — creates tension without head-to-head racing.
6. **Website over app** — one site for info, maps, waiver, briefing; no separate event app to download.
7. **Simple beats clever** — bingo not raffle, playlists not DJ, food trucks not own bar, suggestions not forced group rides.
